# Week 1 Project Scope: ElectricityCast AI

## Project Name
ElectricityCast 

## Domain
Machine Learning

## Problem Statement
Electricity consumption in Malaysia changes from month to month. Energy planners and electricity providers need to understand past usage and estimate future demand to support their planning. ElectricityCast AI will use historical electricity consumption data to train machine learning models that predict future monthly electricity consumption and display the results through an interactive dashboard.

## Initial Project Objectives (2–3)

**O1:** To collect, explore, and prepare historical monthly electricity consumption data from Malaysia's official open data portal.

**O2:** To develop and compare Linear Regression and Random Forest Regression models for predicting future monthly electricity consumption.

**O3:** To evaluate the models using Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE), and display the predictions through an interactive dashboard.

## Target Users

- **Energy planners:** To estimate future electricity demand and support energy planning.
- **Electricity providers:** To understand electricity consumption trends and support resource planning.

The system focuses on national and sector-level electricity consumption. It does not predict individual household electricity bills.

## Similar to EduAdvisor

Both systems aim to help users understand information and make better decisions. ElectricityCast AI presents electricity consumption data and predictions in a clear format so users can understand consumption patterns.

## Different from EduAdvisor

EduAdvisor focuses on education-related information and guidance. ElectricityCast AI focuses on analysing historical electricity consumption data, predicting future consumption using machine learning, and displaying the results through an interactive dashboard.

## Responsible AI Risks (at least 2)

**Risk 1: Inaccurate Predictions**
- The model may produce inaccurate predictions when electricity consumption changes unexpectedly.

**Mitigation:** Test the model using later months that were not used during training, evaluate its performance using MAE and RMSE, and explain that predictions are estimates.

**Risk 2: Misinterpretation of Results**
- Users may believe that the predicted consumption is guaranteed or that it represents electricity usage in their own homes.

**Mitigation:** Clearly display the sector, measurement unit, and prediction period. Explain that the system predicts sector-level consumption rather than individual household bills.

**Risk 3: Data Quality and Updates**
- Some recent electricity consumption figures may be provisional or revised later, which could affect model performance.

**Mitigation:** Check for missing or unusual values, record when the dataset was downloaded, and explain that recent figures may change.
