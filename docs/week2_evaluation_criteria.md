
# Evaluation Criteria


## Evaluation Criteria Table

| Objective / Requirement ID | Evaluation Criterion | Capability Bucket | Measurement Method | Metric | Threshold | User / Business Outcome |
|---|---|---|---|---|---|---|
| O1 / FR3 / NFR1 | Electricity Calculation Correctness | Domain-specific capability | Compare the system's daily and monthly kWh results against manually calculated test cases using different appliance inputs. | Absolute calculation error in kWh | ≤ 0.01 kWh for predefined test cases | Users receive reliable estimates of their household electricity consumption. |
| O2 / FR4 | Dashboard Consistency | Domain-specific capability | Compare dashboard totals by appliance, room, floor, and household against the underlying calculation results. | Percentage of tested dashboard totals that match the calculated values | 100% of defined test cases | Users can understand where their estimated electricity consumption comes from. |
| O1 / FR5 / RAI2 | Estimated Bill Transparency | Instruction-following capability | Test different tariff selections and cases where tariff information is missing or incomplete. Check whether the system identifies assumptions and limitations. | Correct tariff selection and appropriate estimate or missing-information notice rate | 100% of defined test cases | Users understand that the displayed cost is an estimate rather than a guaranteed TNB bill. |
| O3 / FR6 / RAI1 | Recommendation Quality | Generation capability | Evaluate 20 generated recommendations using a rubric covering relevance, practicality, and consistency with household data. | Number of recommendations meeting the rubric | At least 18 out of 20 | Users receive useful suggestions that relate to their household energy usage. |
| O3 / FR6 / RAI4 | Chatbot Numerical Grounding | Instruction-following capability | Ask the chatbot questions about household kWh and estimated costs. Compare its numerical claims with calculation-engine outputs. | Percentage of tested numerical claims that match verified outputs or are correctly labelled as unavailable estimates | 100% | Users receive answers that are consistent with the system's calculated data. |
| O3 / FR7 | What-if Simulator Correctness | Domain-specific capability | Change appliance usage hours or quantities and compare the displayed differences with manually calculated baseline and adjusted values. | Percentage of tested scenarios with correct consumption and cost differences | 100% of defined test cases | Users can compare possible changes before deciding how to reduce energy usage. |
| O1 / NFR2 | Response Latency | Cost and latency | Measure end-to-end response time across a defined workload of local calculations and dashboard operations. Measure external AI responses separately. | p90 latency | ≤ 3 seconds for local operations | Users can interact with the calculator and dashboard without unnecessary delays. |
| O1 / NFR3 | Calculation Reliability | Domain-specific capability | Run at least 50 valid calculation test cases and record whether each completes without errors. | Successful calculation rate | 100% of valid test cases | Users can rely on the calculator to complete valid calculations. |
| O2 / NFR4 | Interface Usability | Generation capability | Ask five intended users to configure a household, enter appliances, and view consumption statistics without assistance. | Number of users completing the tasks without assistance | At least 4 out of 5 users | Users can understand and operate the application more easily. |
| O3 / RAI3 | Privacy Protection | Instruction-following capability | Inspect outgoing AI requests for unnecessary direct personal identifiers using test household profiles. | Number of requests containing unnecessary direct personal identifiers | 0 in the defined test cases | Users' unnecessary personal information is not sent to the external AI service. |
